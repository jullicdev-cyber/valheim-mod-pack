# Fermenter Compatibility 1.0.0

Два узких исправления для установленных AzuCraftyBoxes 1.8.24 и Valheim Plus 0.10.2.0. Оригинальные DLL не изменены: отдельный плагин устанавливает Harmony-проверки на их обработчики бродильни.

- AzuCraftyBoxes обращался к `Player.m_localPlayer.GetInventory()` без проверки наличия персонажа. Автозаполнение Valheim Plus может вызывать этот обработчик во время загрузки/выгрузки персонажа и на выделенном сервере. Проверка пропускает расширенный поиск Azu только для отсутствующего персонажа, отсутствующих аргументов и чужого инвентаря. Обычный поиск ингредиента в переданном сундуке и автоматическая загрузка V+ продолжают работать.
- Valheim Plus менял число готовых предметов у отсутствующего рецепта. Если `GetItemConversion` возвращает `null`, обработчик теперь оставляет этот результат нетронутым. Для существующих рецептов настройка количества сохраняется.

Плагин не перемещает и не создаёт вещи, не меняет рецепты, вместимость или настройки производства. Конфиг не нужен. Обе интеграции устанавливаются независимо и только для проверенных версий; при иной версии плагин пишет предупреждение и пропускает соответствующее исправление.

Сборка: `Build.ps1 -GameDirectory <Valheim>`. Нативные проверки включены в `plugins/ExpeditionLoadouts/Test-Native.ps1`: настоящие обработчики установленных DLL, вызов `Fermenter.FindCookableItem` без персонажа, отсутствующий рецепт, сохранение количества шести предметов у действующего рецепта. Проверки выполняются в отдельном процессе Valheim без загрузки пользовательского мира.

Всем участникам этой сборки нужна одинаковая DLL: World Characters проверяет полный набор модов при подключении.
