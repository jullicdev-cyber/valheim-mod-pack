# Оригинальные тестовые мелодии

`demo-scores.json` содержит три небольшие партитуры, созданные для проверки радио:

- **У огня скальда** — щипковая лира, мягкое сопровождение и редкий рамочный барабан.
- **Тропа через Чёрный лес** — флейтовая мелодия с ритмом путешествия.
- **Под северным сиянием** — спокойная флейта, смычковый фон и лёгкие переборы.

Это синтезированные инструментальные демо в северном фэнтезийном настроении. Сэмплы, сторонние записи и цитаты из существующих мелодий не используются. Продолжительность около 40–50 секунд вместе со вступлением и затуханием.

`Generate-DemoMusic.py` генерирует звук локально: струны и смычковый фон из гармоник, дыхание флейты и барабан из детерминированного шума, тихие отражения, плавное начало и окончание. MP3: 44,1 кГц, стерео, 128 кбит/с; FFmpeg выравнивает громкость с целью −19 LUFS и ограничением истинного пика −2 dBTP.

Нужны Python 3 с NumPy и FFmpeg с кодером libmp3lame. Они нужны только для создания демо; сам игровой мод дополнительных программ не требует.

```powershell
python ./plugins/NordicRadio/Generate-DemoMusic.py --output 'C:\Program Files (x86)\Steam\steamapps\common\Valheim\NordicRadio\Music' --ffmpeg '<путь к ffmpeg.exe>'
```

Для Linux укажите соответствующий каталог игры и `--ffmpeg /usr/bin/ffmpeg`. Скрипт не перезаписывает существующие файлы; если одно из трёх имён уже занято, он останавливается до генерации. Завершённые MP3 публикуются через жёсткую ссылку в той же файловой системе, поэтому требуется файловая система с поддержкой hard links (например NTFS или ext4).

Музыкальные файлы хранятся локально, отдельно от Git и заменяемой папки BepInEx. После добавления файлов нажмите **«Обновить»** в окне рога у хоста или войдите в мир заново. Друзьям вручную копировать мелодии не требуется.
