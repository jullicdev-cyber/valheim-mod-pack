# AnyPortal+

Форк XPortal 1.2.25 для этой сборки: выбор назначения портала с поиском, сортировкой, группировкой по биомам, значками и метками на карте. Исходный XPortal и старый AnyPortal одновременно с ним устанавливать нельзя. [Происхождение исходников и лицензия](ORIGIN.md).

Открой настройки портала обычным взаимодействием с ним. Можно изменить имя, выбрать назначение и необязательный значок портала. По умолчанию значка возле имени нет. Для сохранения настройки нажми «Применить».

Список поддерживает:

- Поиск по названию без учёта регистра.
- Сортировку по имени, расстоянию от текущего портала или дате создания; направление меняется отдельной кнопкой.
- Группировку по биомам с сохранением выбранной сортировки внутри групп.
- Страницы списка и сохранение выбранного назначения при изменении поиска и сортировки.

Навигация по списку по умолчанию назначена на стрелки вверх/вниз. В настройках игры открой «Клавиши модов» (Bindrune), выбери AnyPortal+ и переназначь PreviousPortal/NextPortal; актуальные сочетания показаны в окне. При вводе имени или поиска стрелки управляют курсором текста.

Даты старых порталов неизвестны: игра их не сохраняла. Для новых порталов дата записывается при установке. Старые порталы отображаются с неизвестной датой; дата первого обнаружения не выдаётся за дату создания.

Кнопки меток позволяют создать или обновить личную сохранённую метку текущего портала либо выбранного назначения. Метка ставится в координатах портала и подписывается его сохранённым названием. При отсутствии выбранного значка на карте используется обычный значок портала. Изменения в полях, которые ещё не применены, не подменяют сохранённую настройку портала.

Очистка удаляет только метки, созданные AnyPortal+, либо явно привязанные кнопкой создания метки. Одинаковые ручные метки автоматически не привязываются. После нажатия кнопки на сетевом клиенте запрашивается новый полный список с сервера; при отсутствии ответа в течение 10 секунд очистка отменяется. Затем появляется подтверждение с количеством меток. При подтверждении повторно проверяются мир, персонаж, порталы и сами метки.

Удалённые порталы проверяются по полной базе мира, включая выгруженные далёкие зоны. Переназначение ZDOID при загрузке мира учитывается: существующий портал в прежних координатах сохраняет метку. Ручные переименования, изменения значка и положения не очищаются. Неоднозначные дубликаты сохраняются. После перезапуска полностью идентичную вручную пересозданную метку нативный формат карты не позволяет отличить от прежней привязанной метки.

Метки остаются обычными личными метками Valheim и сохраняются с картой персонажа. Служебные привязки хранятся отдельно для каждого мира и персонажа: `ValheimModpack/AnyPortalPlus/MapPins/<world>-<character>.dat`. Повреждённый файл привязок сохраняется без перезаписи; изменение меток блокируется до устранения ошибки. Установщик не должен удалять эту папку пользовательских данных.

При наличии Confirm Map Pin Removal создание и удаление записываются в существующую историю меток. Ошибка записи истории отменяет удаление. Portal Finder использует тот же полный реестр порталов. Выбор назначения не меняет правила переноса металлов: ими управляют настройки мира.

У хоста, гостей и выделенного сервера должна стоять одинаковая версия AnyPortal+. Обновление выполняется скриптами этой сборки; автоматическая замена на исходный XPortal отключена.

Проверки и сборка выполняются из корня репозитория в PowerShell:

```powershell
./plugins/AnyPortalPlus/Build.ps1 -GameDirectory "C:\Program Files (x86)\Steam\steamapps\common\Valheim"
./plugins/AnyPortalPlus/Test-Markers.ps1
./plugins/AnyPortalPlus/Tests/Test-Core.ps1
./plugins/AnyPortalPlus/Tests/Test-List.ps1
./plugins/AnyPortalPlus/Test-Ui.ps1
./plugins/AnyPortalPlus/Test-PackResources.ps1
./plugins/AnyPortalPlus/Build-UiNativeChecks.ps1 -GameDirectory "C:\Program Files (x86)\Steam\steamapps\common\Valheim"
```

Сборка читает локальные игровые DLL. Для внутренних API создаются временные копии с открытой видимостью только в `.cache`; реальные игровые DLL не заменяются. Тесты логики и изолированного помощника не запускают игру. Для окончательной проверки интерфейса, геймпада и сетевого поведения нужен игровой сеанс.

Build-UiNativeChecks только компилирует отдельную проверочную DLL. Её точка входа `ValheimModPack.AnyPortalPlus.PortalUiNativeChecks.Run()` предназначена для изолированного игрового теста, когда игра закрыта. Проверочную DLL в пользовательскую сборку не копировать.
