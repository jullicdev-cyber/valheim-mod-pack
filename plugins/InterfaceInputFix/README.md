# Interface Input Fix

Клиентский BepInEx-мод `valheimmodpack.interfaceinputfix` 1.0.0 для этой сборки. Требует Jotunn 2.30.2. Не изменяет DLL сторонних модов, инвентарь персонажа, предметы или файлы мира.

В установленном XPortal 1.2.25 каждый `SetActive(true)` добавлял новый запрос блокировки Jotunn, даже при уже открытом окне. Один `Hide` снимал один запрос. `Dispose` уничтожала окно без освобождения запроса. Исправление заменяет только управление этим окном: один принадлежащий ему запрос, идемпотентное закрытие, очистка при уничтожении и выходе, отмена старого отложенного закрытия при новом открытии. Счётчик Jotunn глобально не обнуляется; запросы других модов остаются нетронутыми.

AdventureBackpacks 2.1.13 очищает `BackpackIsOpen` в своём пути обработки клавиатуры, но обычный программный `InventoryGui.Hide()` этот путь обходит. После такого перехода клавиша I могла считать закрытый рюкзак открытым. Prefix вызывает штатный `HideBackpack` только при установленном флаге, с защитой от рекурсивного `Hide`. Доступ к содержимому и сохранение остаются у самого AdventureBackpacks.

Оба исправления включаются только для указанных проверенных версий. При другой версии соответствующее исправление пропускается с предупреждением. По имеющемуся журналу нельзя доказать, какой именно путь вызвал конкретное зависание у пользователя: исправлены найденные воспроизводимые дефекты жизненного цикла.

`Diagnostics / LogBlockedShortcuts = true` добавляет сведения о блокирующих окнах при Ctrl+F/I в BepInEx LogOutput.log. Это только чтение; набранный текст не записывается и блокировки не сбрасываются.

## Проверка

`Test.ps1 -GameDirectory "C:\Program Files (x86)\Steam\steamapps\common\Valheim"` проверяет реальный исходник InputLease/ReentryGuard и компиляцию с установленными API. `NativeChecks.cs` исключён из пользовательской DLL: общий supervised probe проверяет Harmony и настоящее окно XPortal на изолированном объекте, подменяя только тестовый счётчик. Нативный тест сам игру не запускает. Ручная проверка в мире: открыть/закрыть портал, открыть рюкзак, Ctrl+F из инвентаря, закрыть поиск, снова I; аналогично Ctrl+L.
