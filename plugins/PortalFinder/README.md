# Portal Finder 1.0.1

Поиск ближайшего портала по полной базе текущего мира. В сборке используются Valheim 1.0.16, AnyPortal+ 1.3.0 (форк XPortal) и Jotunn 2.30.2. Форк сохраняет GUID и API XPortal, которые использует этот мод.

Открой большую карту. Справа под кнопками истории/пресетов меток находятся:

- **«Ближайший портал ко мне» / Ctrl+J** — поиск от текущей позиции персонажа.
- **«Ближайший портал к точке» / Ctrl+Shift+J** — включи выбор, затем один раз нажми ЛКМ в нужном месте карты. В режиме выбора подпись меняется на **«Отменить выбор точки портала»**; повторное нажатие кнопки или того же сочетания отменяет выбор.

Кнопки показывают действие в первой строке, **текущее назначенное сочетание в квадратных скобках — во второй**. Изменение через Bindrune сразу обновляет подпись, даже без закрытия карты или смены языка. Левые и правые модификаторы отображаются в привычном порядке Ctrl / Shift / Alt / Cmd, независимо от порядка хранения в конфиге. Для `None` показано «Клавиша не назначена» / «Unbound», кнопка мышью остаётся доступна. Подписи размещены в общей колонке карты, кнопки расширены до 420×50 с переносом и подбором размера шрифта от 14 до 17.

Карта центрируется на найденном портале, рядом с кнопками показаны «Портал: <название>» и расстояние в метрах от исходной позиции поиска. Подсказка выбора прямо говорит о поиске ближайшего портала. Маркер временный: новый поиск, закрытие карты и выход из мира убирают его. Постоянные метки, история карты и данные порталов не изменяются. Обычные клики вне режима выбора сохраняют прежнее поведение; клик выбора не создаёт метку даже при последующем двойном клике.

Поиск включает деревянные/каменные, удалённые и не соединённые порталы, в том числе без названия. Расстояние считается по горизонтали, по прямой; это не маршрут по суше и не проверка доступности портала/прав доступа. На карте могут быть показаны порталы в ещё не исследованной области. Результат — снимок на момент явного поиска; перемещение, переименование или разрушение портала не запускает непрерывное сканирование.

У хоста читается постоянный `ZDOMan.GetPortalList()`. У гостей используется синхронизированный полный список XPortal: ожидание первой полной синхронизации отображается отдельно от отсутствия порталов. Без XPortal на сетевом клиенте мод сообщает, что полная база недоступна. Локальный неполный список загруженных объектов не используется как будто он полный. Новый сетевой канал не добавлен.

По умолчанию назначены **Ctrl+J** для поиска от персонажа и **Ctrl+Shift+J** для выбора/отмены точки. Их можно изменить через Bindrune или `BepInEx/config/valheimmodpack.portalfinder.cfg`: `Controls.FindNearestToPlayer` и `Controls.SelectMapPoint`; личные переназначения сохраняются при обновлении сборки. Комбинации действуют только на большой карте, при закрытых окнах и без ввода текста. Левые/правые Ctrl, Alt и Shift равнозначны. Кнопки доступны без назначения клавиш.

При выборе места для метки из пресета кнопки поиска порталов скрываются до завершения/отмены этого инструмента. Это предотвращает одновременное назначение одного клика двум действиям.

Интерфейс русский при русском языке игры и английский при остальных. Смена языка обновляет подписи и временный маркер; названия порталов пользователя не переводятся.

`Test.ps1 -GameDirectory <Valheim>` проверяет геометрический поиск, детерминированные совпадения/дубликаты, независимость результатов, реальный адаптер и контроллер на тестовых заменах окружения, а также контракты API установленных DLL. Для 1.0.1 прошли 59 проверок поиска, 22 адаптера, 50 UI/controller и 95 API-контрактов. Проверяются потребление клика/двойного клика, сохранность обычных меток, закрытие карты, смена мира, локализация и конфликт с выбором места для пресета; новые проверки охватывают рабочие defaults, актуализацию подписей после переназначения, длинные сочетания, `None` и порядок модификаторов BepInEx. Это проверки кода и контрактов, без живой Unity-сессии. Полная визуальная проверка карты и сетевого клиента дополнительно требуется. В World Characters сравнивается весь набор DLL, поэтому сборку следует обновить у всех игроков.
