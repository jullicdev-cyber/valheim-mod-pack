# Portal Finder 1.0.0

Поиск ближайшего портала по полной базе текущего мира. В сборке используются Valheim 1.0.16, XPortal 1.2.25 и Jotunn 2.30.2.

Открой большую карту. Справа под кнопками истории/пресетов меток находятся:

- **«Ближайший ко мне»** — поиск от текущей позиции персонажа.
- **«Ближайший к точке»** — включи выбор, затем один раз нажми ЛКМ в нужном месте карты. Повторное нажатие кнопки отменяет выбор.

Карта центрируется на найденном портале, рядом с кнопками показаны его название и расстояние в метрах от исходной позиции поиска. Маркер временный: новый поиск, закрытие карты и выход из мира убирают его. Постоянные метки, история карты и данные порталов не изменяются. Обычные клики вне режима выбора сохраняют прежнее поведение; клик выбора не создаёт метку даже при последующем двойном клике.

Поиск включает деревянные/каменные, удалённые и не соединённые порталы, в том числе без названия. Расстояние считается по горизонтали, по прямой; это не маршрут по суше и не проверка доступности портала/прав доступа. На карте могут быть показаны порталы в ещё не исследованной области. Результат — снимок на момент явного поиска; перемещение, переименование или разрушение портала не запускает непрерывное сканирование.

У хоста читается постоянный `ZDOMan.GetPortalList()`. У гостей используется синхронизированный полный список XPortal: ожидание первой полной синхронизации отображается отдельно от отсутствия порталов. Без XPortal на сетевом клиенте мод сообщает, что полная база недоступна. Локальный неполный список загруженных объектов не используется как будто он полный. Новый сетевой канал не добавлен.

По умолчанию горячие клавиши не назначены. Их можно задать через Bindrune или `BepInEx/config/valheimmodpack.portalfinder.cfg`: `Controls.FindNearestToPlayer` и `Controls.SelectMapPoint`. Комбинации действуют только на большой карте, при закрытых окнах и без ввода текста. Левые/правые Ctrl, Alt и Shift равнозначны. Кнопки доступны без назначения клавиш.

При выборе места для метки из пресета кнопки поиска порталов скрываются до завершения/отмены этого инструмента. Это предотвращает одновременное назначение одного клика двум действиям.

Интерфейс русский при русском языке игры и английский при остальных. Смена языка обновляет подписи и временный маркер; названия порталов пользователя не переводятся.

`Test.ps1 -GameDirectory <Valheim>` проверяет геометрический поиск, детерминированные совпадения/дубликаты, независимость результатов, реальный адаптер и контроллер на тестовых заменах окружения, а также контракты API установленных DLL. Проверяются потребление клика/двойного клика, сохранность обычных меток, закрытие карты, смена мира, локализация и конфликт с выбором места для пресета. Полная живая проверка карты и сетевого клиента дополнительно требуется. В World Characters сравнивается весь набор DLL, поэтому сборку следует обновить у всех игроков.
