# Клавиши сборки 1.10.0

Добавлен [Bindrune 0.5.0](https://thunderstore.io/c/valheim/p/isimp/Bindrune/). В настройках Valheim появилась кнопка **«Клавиши модов» / Mod keys**. Открыть то же окно можно клавишей **Insert**; её тоже можно переназначить. Интерфейс самого Bindrune преимущественно английский.

Выберите действие через поиск, нажмите его привязку и задайте новую клавишу/сочетание. Для персональных настроек используйте **Just for you**. **Whole profile** меняет общий конфиг; такое изменение может замениться при обновлении сборки. Подсказки HUD включаются по **Alt+H** и настраиваются в Bindrune.

## Наши действия

| Мод и настройка | По умолчанию | Где работает |
|---|---|---|
| Chest Search → General → OpenShortcut | Ctrl+F | Открыт инвентарь |
| Expedition Loadouts → Controls → OpenShortcut | Ctrl+L | Открыт инвентарь |
| Expedition Loadouts → Controls → LargeAmountModifier | Shift | Кнопки −/+ в окне набора, шаг 10 |
| Confirm Map Pin Removal → Controls → OpenHistory | Ctrl+H | Большая карта |
| Confirm Map Pin Removal → Controls → QuickPin | Ctrl+P | Игровой мир или карта |
| Confirm Map Pin Removal → Controls → PlaceOnMapModifier | Shift + ЛКМ | Выбор пресета для точки карты |
| Confirm Map Pin Removal → Controls → RenamePinModifier | Alt + ЛКМ | Переименование метки |
| EAQS Quick Stack Bridge → Controls → SortShortcut | O | Сортировка обычных слотов инвентаря |

В модификаторах клика переназначается удерживаемая клавиша/комбинация; ЛКМ остаётся выбором точки или метки. Можно снять назначение: `None` не превращает обычный клик в действие. У карты левый и правый Ctrl/Shift/Alt равнозначны; лишние модификаторы отвергаются. Подписи кнопок карты больше не содержат фиксированное Ctrl+H/Ctrl+P.

У радио действия используют штатное взаимодействие, использование предмета и панель быстрого доступа — их клавиши берутся из управления игры. У таймеров ресурсов собственных хоткеев нет. Escape/кнопка возврата остаются обычным закрытием окон. Ctrl+F/I в диагностике InterfaceInputFix только записывают состояние фокуса при включённой диагностике, не выполняют игровых действий.

У сторонних модов уже доступны типизированные настройки: Equipment and Quick Slots (включая Keypad1–3), Adventure Backpacks, PlantEasily, AzuAutoStore, AzuCraftyBoxes и Valheim Plus. Их DLL не изменены. Клавиша быстрого складывания K переназначается в **AzuAutoStore**. Избранное продолжает защищаться нашим EAQS Quick Stack Bridge.

**Сортировку переназначайте в EAQS Quick Stack Bridge.** Запись Quick Stack → SortKeybind в Bindrune доступна только для просмотра. Опасные для этой сборки команды Quick Stack (массовое складывание, пополнение, удаление) также остаются недоступны для включения через Bindrune. Это сохраняет уже установленную защиту ячеек EAQS. При сохранении конфигурации сторонним менеджером на диске сохраняются `SortKeybind = None`, `DisplaySortButtons = OnlyContainerButton`; разрешение сортировки и выбранная клавиша включаются в памяти только нашим патчем.

## Что сохраняется при обновлении

Установщики Windows и Linux переносят из прежней установки:

- `BepInEx/bindrune.keys` — личные назначения и настройки панели;
- `BepInEx/bindrune.spare` — резервная копия Bindrune;
- `BepInEx/config/isimp.Bindrune.cfg` — собственный конфиг менеджера;
- `BepInEx/config/Bindrune/situations.txt` — пользовательские описания контекстов.

`config/Bindrune/known.txt` содержит общие контексты наших команд для анализа конфликтов и включён в воспроизводимую сборку. Контексты описывают назначение клавиш; они сами не меняют обработку ввода. Личные настройки не включены в Git. Установщик по-прежнему делает полный бекап корня игры до замены файлов.

## Исправления совместимости

В оригинальном Bindrune 0.5.0 повторное `Close()` без открытого окна снимало чужую блокировку Jotunn, а повторное `Open()` добавляло лишнюю. Это воспроизведено на оригинальной DLL в изолированном процессе. InterfaceInputFix 1.1.0 заменяет только эти запросы через Harmony: один запрос принадлежит одному окну, повторные вызовы безопасны, скрытие окна освобождает запрос. Чужие блокировки не сбрасываются. Адаптер включается только для проверенной версии 0.5.0.

Вход из настроек добавлен нашим адаптером. Пока Bindrune открыт, навигация настроек заблокирована, а клавиша закрытия не проходит в нижележащее окно в тот же кадр. Кнопка размещена между штатными нижними кнопками; пересечения с кнопками настоящего префаба Settings проверены программно.

## Выполненные проверки

Дата: 27 сентября 2026. Windows, Valheim 1.0.16, Jotunn 2.30.2, BepInEx 5.4.2351.

- Все моды сборки загружены в два последовательных изолированных процесса настоящего Valheim с графическим клиентом. Игровой мир не запускался; отдельные каталоги BepInEx и сохранений не затрагивали персонажей пользователя.
- Bindrune обнаружил **150 привязок**, включая служебные и доступные только для просмотра. Проверены девять записей BepInEx: реальные изменения сочетаний, обновление сортировщика, запрет опасных команд и сохранение безопасного конфига Quick Stack.
- Во втором процессе общие cfg были заменены стандартными из сборки; все девять личных сочетаний восстановились из `bindrune.keys`. **128 проверок Bindrune в первом процессе и 119 во втором**, включая реальные окна и Settings, идемпотентность и освобождение собственного запроса ввода, распознавание новых сочетаний карты и выключение через None.
- В обоих процессах также прошли проверки остальных модов: 31 базовая, 23 UI поиска, 9 ввода, 60 таймеров, 40 истории/подтверждения, 35 UI пресетов и 32 моста избранного. [Вывод двух запусков](controls-1.10.0-native.txt).
- Host-тесты карты: 31/56/63/38/59, быстрых меток: 55, хранения пресетов: 49. Проверки границ слотов моста, переназначения сортировки и 39/27 проверок избранного; 18 проверок жизненного цикла InputLease. Эти тесты используют doubles и не заменяют игру.
- Тесты установщиков: 9 сценариев, 7 успешно, 2 пропущены из-за отсутствия права создавать символьные ссылки Windows. Проверены сохранение личных файлов, повторная установка, восстановление при ошибке и полный бекап. Python-ветка Linux проверялась на Windows; нативного Linux-запуска не было.
- Пакет: 128 хешей, 18 внешних пакетов, 24 GUID плагинов, 26 DLL; зависимости сходятся. Пересборка через `scripts/Build.ps1` совпала с манифестом.

В журнале Bindrune есть однократное предупреждение о чтении `HotbarUse`: это служебная подсказка всей панели без самостоятельной привязки. Сканер пропускает её; обычные слоты и действия продолжают обнаруживаться. Это штатно обработанный случай в исходнике `VanillaScanner`, не ошибка загрузки мода.

**Границы:** это проверка API, настроек, логики и интерфейса в игровом процессе, а не прохождение в мире на восемь человек. Физические нажатия всех сочетаний, визуальное удобство на разных разрешениях, работа в бою/на корабле и применение серверных конфигов при подключении требуют проверки в обычной игре. Конфликты Bindrune диагностирует, но автоматически не устраняет. Гарантировать отсутствие любых ошибок нельзя.

`KeyboardShortcut` поддерживает комбинации; настройки сторонних модов типа `KeyCode` допускают только одну клавишу — модификаторы Bindrune отбросит с сообщением. Строковые настройки и часть фиксированных/контроллерных действий могут быть доступны лишь для просмотра. Жёстко заданные клавиши внутри чужих DLL Bindrune сам по себе не переписывает. Изменение привязки также не включает отключённую игровую функцию.

Исходники Bindrune изучены по [ревизии fba888bf](https://github.com/isimp/Bindrune/tree/fba888bf2b299e27876f8e2bebc2cfefd35e1d3d); архив 0.5.0 и его хеш закреплены в `mods.lock.json`. Оригинальная DLL и лицензия MIT сохранены. Наша интеграция: `plugins/InterfaceInputFix/BindruneCompat.cs`; её исполняемые проверки: `BindruneNativeChecks.cs`.
