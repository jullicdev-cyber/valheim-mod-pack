# Проверка обновления 1.9.0 — 27 сентября 2026

Valheim 1.0.16, BepInEx 5.4.2351, Jotunn 2.30.2; исходные DLL сторонних модов не изменены.

## Исправления ввода

В IL XPortal 1.2.25 подтверждено: каждый вызов `SetActive(true)` увеличивал общий счётчик Jotunn, включая повторное открытие; `Dispose` уничтожала панель без освобождения запроса. `InterfaceInputFix` владеет одним запросом для этой панели, отменяет устаревшее отложенное закрытие/фокус и освобождает только свой запрос. Глобального сброса счётчика нет.

AdventureBackpacks 2.1.13 очищает `BackpackIsOpen` своим методом `HideBackpack`, но переходы наших окон через `InventoryGui.Hide` обходили этот путь. Патч вызывает штатное закрытие рюкзака при активном флаге и защищает рекурсивный вызов Hide. Инвентари и сохранение остаются под управлением AdventureBackpacks.

ConfirmMapPinRemoval 1.3.1 освобождает свой запрос после внешнего скрытия/уничтожения окна истории и до повторного открытия. Старые события кнопок не действуют на новое окно. ChestSearch/Loadouts учитывают активность и наследников TMP-полей при проверке фокуса.

Журнал пользователя не позволяет доказать, какой именно путь вызвал наблюдавшееся зависание. Исправлены конкретные выявленные дефекты; полное воспроизведение пользовательской последовательности в живом мире ещё требуется. В InterfaceInputFix есть отключённый по умолчанию `Diagnostics/LogBlockedShortcuts`: он записывает состояния окон, но не введённый текст.

## Поиск и комплекты

ChestSearch 1.1.0 группирует по точному prefab, отображает штатную иконку, суммарное количество, число сундуков и ближайшую дистанцию. Все четыре сортировки имеют ASC/DESC. Пустой запрос показывает список только при явной галочке. Подсветка создаётся только отдельной командой для выбранного типа; доступ и наличие предмета проверяются повторно. Поиск и маркеры не запрашивают владение и не пишут в сундуки. Качество/зачарования одного prefab суммируются в поиске.

ExpeditionLoadouts 1.1.0 читает обычную экипировку, hotbar и EAQS в снимок и учитывает их при подсчёте имеющегося. Для пополнения сравниваются prefab, качество, вариант и world level; обычные экземпляры с разной прочностью/изготовителем подходят, сохраняя эти свойства при штатном переносе. Предметы с customData пропускаются с пояснением, не заменяются обычными аналогами. Пополнение по-прежнему обходит специальные и защищённые ячейки. Формат пресетов v2 читает v1; при сохранении остаётся `.bak`.

## Растения

PlantEverything: четыре возобновляемых вида грибов 30 минут, четыре ягодных куста 45, чертополох/одуванчик/папоротник 50. RenewableResourceTimers 1.0.0 отдельно задаёт лозе 45 минут и двум саженцам грибов Туманных земель 1800 секунд роста. Последние сохраняют одноразовый сбор, включая природные экземпляры. Другие культуры, деревья, камни и кремень не меняются. Сохраняются timestamps, урожайность, расстояния посадки и начальная случайная зрелость лозы.

Два дополнительных параметра синхронизируются через штатные admin-only настройки Jotunn; мод одной версии нужен всем участникам. Автоматические проверки подтверждают теги и API синхронизации, но не моделируют соединение нескольких настоящих клиентов. Возобновление происходит на штатном игровом тике, а не с точностью до секунды.

## Проверки

- ChestSearch: 100 проверок реальных исходников; 23 проверки UI на настоящих компонентах Jotunn, реальный спрайт Iron и 6050 алиасов локализации.
- ExpeditionLoadouts: 85 backend и 23 persistence проверки. Общий native probe: 29 проверок загрузки, разрешённых контейнеров, защищённых ячеек и настоящего `Inventory.MoveItemToThis`, включая обычный меч с сохранением прочности/изготовителя.
- InterfaceInputFix: 18 проверок lease/reentry; 9 нативных проверок реальных Harmony hooks и XPortal SetActive/Hide/Dispose с изолированной панелью. Тест подменяет счётчик ввода, чтобы сохранить состояние меню; API рюкзака проверен без мутации инвентаря персонажа.
- RenewableResourceTimers: 44 проверки политики; 60 проверок настоящих prefab, полей неактивных копий, сохранности исходных assets, тегов конфигурации и Harmony hooks.
- ConfirmMapPinRemoval: 586 host-проверок; 40 native history/confirmation и 35 preset UI проверок, включая уничтожение/скрытие окна и устаревшие кнопки.
- Существующий EAQS/Azu/Quick Stack bridge: 32 native проверки общих favorites, сериализации и повторных загрузок.
- Готовый пакет: 124 SHA-256, 17 внешних пакетов; 23 plugin GUID и 25 assemblies, без заявленных hard conflicts, отсутствующих зависимостей или дублирующихся GUID.

Успешный общий запуск: `.cache/qol-native-6b619b84/result.txt`. Запущен отдельный процесс игры с отдельными BepInEx и Saves; живой мир пользователя не открывался. Начальный пробник требовал явного создания GUI и включения YamlDotNetDetector для рюкзака; после исправления тестового окружения общий запуск прошёл.

Нативный запуск проверяет API, UI-объекты и отдельные сценарии, но не заменяет визуальную проверку, реальные нажатия Ctrl+F/I и сетевую игру. В меню блокировка движения Jotunn не действует; проверки баланса выполнены также на исходниках и тестовом счётчике.

## После установки

Локальная установка выполнена с предварительной полной копией корня игры: `ValheimModpack-backups/20260927-153037-qol-190/full-backup`. Заменены пять локальных DLL; два конфига объединены по секциям и ключам. Остальные 134 прежних файла модов, настроек, персональных данных и музыки совпадают с резервной копией. Все семь установленных локальных DLL совпадают с Git-пакетом; изменённые — также с успешно проверенными DLL. Сохранения Valheim вне папки игры эта копия не включает.

Проверить в обычном мире: открыть/закрыть настройки портала несколько раз → I → закрыть рюкзак через Ctrl+F → закрыть поиск → I; аналогично Ctrl+L. В поиске включить показ без ввода, переключить все сортировки, выбрать один тип, подсветить сундуки, забрать предмет вторым игроком. Для старого походного набора нажать «Добавить из инвентаря» либо создать новый набор. Обновление сборки требуется всем участникам.
