# Повторная проверка собственных модов — 27 сентября 2026

Проверены все семь модов, созданных для этой сборки. Среда: установленный Valheim 1.0.16, Unity 6000.0.75, BepInEx 5.4.2351, Jotunn 2.30.2. Проверка включала чтение производственного кода, IL используемых сторонних API, регрессионные тесты и изолированные запуски настоящего движка. Сторонние DLL не изменены.

## Исправленные ошибки

| Мод | Версия | Найденное поведение и исправление |
| --- | --- | --- |
| ExpeditionLoadouts | 1.1.1 | Флаг контейнера мог отключить проверку охранного камня; теперь она обязательна. NaN-координаты больше не проходят проверку радиуса. Нулевая ревизия не считается загруженным сундуком. Неверные размеры инвентаря отвергаются до перебора ячеек. ID персонажа 0 не используется; изменение ID обновляет контекст даже при том же объекте Player. |

Перед заменой проверяется исходный SHA-256; обнаруженное изменение, создание, удаление или повреждение файла останавливает запись. Файл и его `.bak` сохраняются. Чтение и размер графа JSON ограничены; ошибка замены не фиксирует черновик в памяти. |
| EAQSQuickStackBridge | 1.1.1 | Повторная инициализация защиты Azu могла дублировать hooks и пересоздать привязку избранного. Инициализация и завершение теперь выполняются однократно. Размеры выше 32 рядов блокируют операции с ячейками. |
| ConfirmMapPinRemoval | 1.3.2 | Ожидающее подтверждение удаления проверяло объекты карты/игрока, но не мир, сессию и ID персонажа. Теперь весь этот контекст проверяется повторно; чат, консоль, инвентарь и другое штатное окно отменяют запрос. Ctrl+P учитывает активные поля ввода, унаследованные от TMP_InputField. |
| NordicRadio | 1.1.2 | Отложенное открытие идола могло перекрыть чат, консоль или чужое модальное окно. Добавлены проверки до получения собственного запроса блокировки; Escape/B отменяют ожидание. Уже открытое окно закрывается при смене контекста, проверяя штатную панель ввода отдельно от своего запроса Jotunn. |

Для основных исправлений добавлены регрессии, воспроизводившие неверное поведение до правки. Исходные инвентари, миры и персонажи пользователя не использовались как тестовые данные.

## Границы результата

Изолированные запуски используют отдельные BepInEx и Saves и не открывают мир пользователя. Проверки меню/headless подтверждают API и работу объектов UI, но не заменяют реальные нажатия клавиш, визуальную проверку и несколько настоящих клиентов. Движение предметов между восемью участниками, нестабильная сеть и длительный игровой сеанс не воспроизведены. Linux runtime в этом аудите не запускался.

Проверка SHA-256 файла наборов обнаруживает изменения до записи, но не является транзакционной блокировкой для стороннего редактора: между проверкой и заменой остаётся короткая гонка при строго одновременной записи из другого процесса. Обычная работа одного экземпляра игры не создаёт параллельных писателей.

Для игровой приёмки: несколько раз открыть портал, рюкзак и поиск; сортировать с заполненными EAQS/избранными ячейками; проверить K до и после снятия избранного; пополнять комплект двумя игроками около доступного и закрытого охранным камнем сундука; открыть чат во время ожидания радио и подтверждения метки; проверить отмену Escape. Эти сценарии нужно проводить на тестовом персонаже, а не трактовать результаты аудита как гарантию отсутствия багов.
