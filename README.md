# Valheim — сборка 1.4.6

**Изменение 1.4.6.** Добавлен клиентский Confirm Map Pin Removal 1.0.0: удаление сохранённой метки правым кликом требует подтверждения в штатном окне «Да / Нет». Для русского языка игры текст запроса русский. Отмена сохраняет метку; подтверждение удаляет только первоначально выбранную и всё ещё существующую метку. Автоматическое удаление меток не перехватывается. Пройдены тесты состояния подтверждения и статическая проверка API Valheim 1.0.16; игровой тест ещё требуется. [Исходники и ограничения](plugins/ConfirmMapPinRemoval/README.md).

**Изменение 1.4.5.** Исправлен запуск EAQS Quick Stack Bridge 1.0.1: он ждёт создания настроек Quick Stack в Start, прежде чем включать сортировку по O и кнопки. Устранён KeyNotFoundException из журнала игры. Добавлен регрессионный тест отложенной и частичной инициализации настроек на настоящем исходнике патча с тестовыми заменами окружения. Полный игровой тест сортировки ещё требуется.

**Изменение 1.4.4.** Добавлен локальный EAQS Quick Stack Bridge 1.0.0 для Quick Stack 1.4.15 и EAQS 3.1.3. Патч использует API EAQS и защищает все специальные ряды от сортировки, включая пустые ячейки. После успешного подключения включает сортировку обычного инвентаря по O и кнопкой; дополнительный ряд +8 сохраняется. Исходные DLL модов не изменены. Перенос/пополнение Quick Stack остаются отключены. Пройдены проверки границ и API; игровой тест ещё не выполнен. Исходники и ограничения: [EAQSQuickStackBridge](plugins/EAQSQuickStackBridge/README.md).

**Изменение 1.4.3.** Базовая грузоподъёмность V+ повышена с 300 до 450 (+50%; без бонусов экипировки). Включён встроенный режим первого лица Valheim Plus: Home переключает вид, PageUp/PageDown меняют угол обзора, начальный FOV 65. Отдельная DLL камеры не добавлялась. EAQS Base Carry Weight остаётся 300 и не переопределяет вес V+. После обновления требуется перезапуск игры; игровой тест камеры и грузоподъёмности ещё не выполнен.

**Изменение 1.4.2.** Из-за конфликта Quick Stack 1.4.15 с EAQS 3.1.3 отключены сортировка инвентаря (клавиша O и кнопка), кнопки складывания, пополнения и «Отдать всё» этого мода. Оставлена только кнопка сортировки открытого сундука. Дополнительный ряд EAQS сохранён. Это ограничение опасных операций, а не исправление совместимости DLL или восстановление пропавших предметов. Требуется перезапуск игры и обновление конфигов у остальных игроков.

**Изменение 1.4.1.** Основной инвентарь расширен на один ряд (+8 ячеек) через Equipment and Quick Slots: `Extra Inventory Rows = 1`. Расширение V+ выключено из-за несовместимости; три быстрых слота и слоты экипировки сохранены. Всем участникам следует обновить сборку; после установки требуется перезапуск игры. Игровая проверка отображения и сохранения нового ряда ещё не выполнена.

Сборка подготовлена 25 сентября 2026 года для Windows и нативного Linux. Локальная версия игры — **1.0.16**, определена по существующему журналу BepInEx. **Новый ValheimPlus от Grantapher 0.10.2.0 официально проверен автором только с Valheim 1.0.15 и BepInEx 5.4.2350. Совместимость с установленными 1.0.16 / 5.4.2351 не подтверждена.** Игровой запуск этой сборки ещё не проверен. ## ValheimPlus: форк и настройки

Используется **Grantapher/ValheimPlus_Grantapher_Temporary**, а не старый оригинальный пакет. Стабильный релиз [0.10.2.0 от 20 сентября 2026](https://github.com/Grantapher/ValheimPlus/releases/tag/0.10.2.0) сверён с GitHub и Thunderstore. Заявленная автором совместимость сохранена в `third-party/Grantapher-ValheimPlus_Grantapher_Temporary/COMPATIBILITY.md`.

Активный файл: **`Game/BepInEx/config/org.bepinex.plugins.valheim_plus.cfg`**. Его исходная копия для пересборки — `config/org.bepinex.plugins.valheim_plus.cfg`. Старый пользовательский конфиг сохранён только для справки в `reference/valheim_plus.cfg.original` и не устанавливается.

Из прежнего конфига перенесены:

- Вес предметов −50%; время действия еды +50%.
- Защита построек от дождя/воды, дальность строительства 20 м, радиус комфорта 10 м. Защита от лавы и сильного снега отдельно не включена.
- Камера: отдаление 20 м и FOV 90°.
- Расширенное строительство (F1/F3), редактирование построек (NumPad0). Дополнительные перекаты из старого конфига сейчас отключены.
- Сон в незанятой кровати без смены точки возрождения.
- Ульи: 600 секунд на мёд, вместимость 20; бродильные бочки: 1200 секунд, 6 предметов, показ времени.
- Синхронизация конфигурации с сервером и проверка версии V+.

**Добыча по-прежнему ×2, древесина ×6** при модификаторе мира ×2. В V+ отключены `Gathering`, `Pickable`, `LootDrop`; ResourceDropModifier остаётся единственным дополнительным множителем древесины. Старое `wood = 1000` не перенесено. Порталы остаются под управлением модификатора мира Casual, `Items.noTeleportPrevention` в V+ выключен.

Крафт и хранение обслуживают AzuCraftyBoxes/AzuAutoStore. В V+ выключены CraftFromChest, AutoStack, HUD и изменения инвентаря. С 1.4.0 загрузку плавильни, доменной/углевыжигательной печей и источников огня выполняет AutomaticFuel; autoFuel V+ для этих четырёх групп выключен. Автовыгрузка V+ выключена. Ценная и цельная древесина исключены из топлива и сырья AutomaticFuel; лимит угля в ближайших сундуках — 100. Настройки бродильни, мельницы и прялки в V+ этим добавлением не меняются.

Остальные настройки добавленных модов создаются с авторскими значениями по умолчанию.

## Автоматическая передача угля

Поставь плавильню рядом с выходом углевыжигательной печи: **не дальше 5 м от выпавшего угля**. Уголь выпадает обычным способом, AutomaticFuel подбирает его с земли и загружает в плавильню, пока в ней есть место. Промежуточный сундук не обязателен. С земли также подбираются подходящие руда и обычная древесина.

Топливо и сырьё из сундуков берутся в радиусе **10 м**. Настроена загрузка по одному предмету за проход; в сундуках остаётся образец предмета для AzuAutoStore. Открытые сундуки и доступ к ним проверяются модом. Если рядом настроен AzuAutoStore, он тоже может собрать уголь с земли в сундук, откуда AutomaticFuel затем возьмёт его.

Обычная работа дыма и список руд доменной печи сохранены. Ценная/цельная древесина не расходуется. Автозагрузка углевыжигательной печи ограничена запасом в 100 угля в ближайших сундуках; ранее загруженная древесина может доработать. Горячая клавиша выключения AutomaticFuel отключена, чтобы не конфликтовать с PlantEasily.

Мод нужен у всех игроков группы; для сервера используется та же сборка. Автоматика зависит от активной зоны и клиента, владеющего устройством: работа на пустом выделенном сервере не обещается. После обновления проверить цепочку на нескольких единицах угля, затем при двух одновременно играющих клиентах. Восемь игроков и передача владения зоной в игре ещё не проверены. [Описание автора](https://thunderstore.io/c/valheim/p/TastyChickenLegs/AutomaticFuel/).

Конфиг: `config/TastyChickenLegs.AutomaticFuel.cfg`. У AutomaticFuel выключено управление мельницами и прялками; их прежние настройки V+ сохраняются. Бродильнями этот мод не управляет.

## Сортировка и быстрая выгрузка

- Quick Stack + локальный Bridge: после подключения патча доступны сортировка инвентаря по **O** и кнопки. При открытом сундуке **O** сортирует сундук. Если патч не загрузился, доступна только кнопка сундука. Команды переноса Quick Stack остаются отключены.
- Выгрузка сразу по ближайшим сундукам без их открытия — **AzuAutoStore: K** (английская раскладка), радиус по умолчанию 5 м. В сундуках уже должны быть образцы соответствующих предметов. **Shift+K** переключает паузу автосбора. Клавиша `.` остаётся управлению масштабом миникарты.
- Массовое удаление выключено, корзина скрыта, клавиши удаления отключены. Областная раскладка/пополнение Quick Stack в мультиплеере без MultiUserChest остаются выключенными; MultiUserChest в комплект не добавлен.
- Три быстрых слота EAQS (Num1–3) заполняются вручную: включён `Prevent auto-pickup into quick slots`. Подбор по-прежнему может пополнять уже существующие стопки. Число слотов и их содержимое не меняются. Проверка сообщений об исчезновении вещей описана в [диагностике инвентаря](INVENTORY-DIAGNOSTIC.md).

Конфиги: `config/goldenrevolver.quick_stack_store.cfg`, `config/Azumatt.AzuAutoStore.cfg` и копии в `Game/BepInEx/config`. Клавиши и кнопки переноса Quick Stack отключены; сортировка доступна только кнопкой сундука.

Версия 1.4.15 содержит авторское исправление совместимости с новым EAQS, но полноценную поддержку его API автор ещё планирует. До общего прохождения проверь сортировку, избранное, дополнительные слоты EAQS, зачарованные предметы и содержимое рюкзака на тестовом персонаже. Это не обещание автоматического пополнения дополнительных быстрых слотов. [Описание автора](https://thunderstore.io/c/valheim/p/Goldenrevolver/Quick_Stack_Store_Sort_Trash_Restock/).

## Установка

### Автоматически — Windows

Дважды нажми `Install-Windows.cmd` в корне репозитория и вставь путь к папке с `valheim.exe`. Либо выполни из PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Install-Windows.ps1 -GameDirectory "C:\Program Files (x86)\Steam\steamapps\common\Valheim"
```

Нужен Windows PowerShell 5.1 или новее. Если запись в каталог игры запрещена, запусти установщик от имени администратора.

### Автоматически — Linux

Нужны Bash и Python 3.9 или новее. Установщик предназначен для **нативной Linux-версии**, с файлом `valheim.x86_64`, не для Proton и не для выделенного сервера.

```bash
bash Install-Linux.sh
# Или сразу с путём:
bash Install-Linux.sh "$HOME/.local/share/Steam/steamapps/common/Valheim"
```

После установки укажи в Steam → Valheim → Свойства → Параметры запуска:

```text
./valheim-modded.sh %command%
```

Либо запускай созданный `valheim-modded.sh` из папки игры при запущенном Steam. Установщик выдаёт скриптам права запуска и нормализует переводы строк. Не запускай через Proton: там нужен другой механизм загрузки.

### Что делают установщики

Перед запуском закрой игру. Установщики проверяют папку и контрольные суммы сборки, затем делают **полную резервную копию содержимого папки Valheim** в `ValheimModpack-backups/<уникальная-папка>/full-backup`. В неё входят прежние моды, конфиги, все файлы в корне, включая исполняемые файлы игры, и остальные подпапки. Исключается только `ValheimModpack-backups`, чтобы старые копии не копировались повторно. Потребуется свободное место под всю игру и моды; копирование может занять несколько минут. Если копирование завершилось ошибкой, замена модов не начинается. Файл `BACKUP-COMPLETE.txt` рядом с копией отмечает успешное завершение бэкапа.

После бэкапа установщик подготавливает файлы сборки и заменяет `BepInEx` целиком. Дополнительно заменяемые оригиналы перемещаются в подпапку `original` для быстрого отката. При повторной установке создаётся новая полная резервная копия; текущие настройки модов также сохраняются. При ошибке замены выполняется попытка автоматического отката; при аварийном завершении процесса копия остаётся для ручного восстановления. Windows-установщик сохраняет содержимое файловых символических ссылок Vortex как обычные независимые файлы в full-backup; исходные ссылки остаются в original при переносе прежних модов. Ссылки на каталоги/junction и неподдерживаемые reparse points блокируются без обхода внешних каталогов. Недоступная цель файловой ссылки также останавливает установку до замены модов. Linux сохраняет символические ссылки как ссылки, без копирования внешних данных. Закрой Vortex на время установки; повторное развёртывание старого профиля Vortex может вернуть прежние моды.

Для быстрого отката закрой игру, перенеси установленные файлы сборки в отдельную папку, затем верни содержимое `original` в каталог игры. Перечень заменённых элементов записан рядом в `INSTALL.txt`. Для полного восстановления перенеси текущее содержимое игры, кроме каталога резервных копий, в отдельную папку и верни содержимое `full-backup`. Простое объединение папок оставит новые файлы, которых не было в старой сборке. Игровые файлы только копируются в резервную копию, а не заменяются установщиком. Сохранения вне каталога игры, например в AppData или Steam Cloud, в этот бэкап не входят. Настройки мира **Ресурсы ×2** и **Portals Casual** по-прежнему выбираются отдельно.

### Вручную

1. Закрой Valheim. Сделай резервную копию мира и персонажа через управление сохранениями в игре.
2. Открой папку игры через Steam → Valheim → Управление → Просмотреть локальные файлы. Обнаруженный здесь путь: `C:\Program Files (x86)\Steam\steamapps\common\Valheim`.
3. **Не объединяй сборку со старой папкой BepInEx.** В существующем журнале обнаружены старые Valheim Plus 0.9.16.2, PlantingPlus, Smart Containers и другие моды. Закрыв игру, перенеси старую папку `BepInEx` в отдельную резервную папку вне каталога игры. Сохрани туда же старые `winhttp.dll`, `doorstop_config.ini` и `.doorstop_version`, если они есть. Это позволит откатить замену.
4. Скопируй **содержимое папки `Game`** этой сборки в папку с `valheim.exe`. Папка `BepInEx` должна оказаться рядом с `valheim.exe`, а не внутри дополнительной папки `Game`.
5. Выполни две настройки мира из следующего раздела **до начала игры**.
6. Запусти Valheim обычным способом через Steam. Остальные конфиги модов создадутся автоматически с авторскими настройками по умолчанию.

Сборка только подготовлена в этой рабочей папке. Существующая установка игры и сохранения не изменялись. `valheim.exe`, игровые ресурсы и сохранения в комплект не входят.

## Обязательно: две настройки конкретного мира

Множитель общей добычи и правила переноса через портал хранятся в самом мире. Копирование модов их не устанавливает. `world-settings.json` описывает нужные значения, но игра не читает этот JSON автоматически.

В меню выбора мира открой **«Модификаторы мира» / World Modifiers** и установи:

- **Ресурсы / Resource rate: ×2**.
- **Порталы / Portals: Casual**, вариант, разрешающий перенос всех предметов, включая руду и металлы.

Измени именно эти два параметра; выбирать общий пресет сложности Casual не требуется. Настройку нужно применить отдельно к каждому используемому миру, у владельца мира или на сервере.

После этого результат:

| Что добывается | Множитель мира | Дополнительный множитель мода | Итог |
| --- | --- | --- | --- |
| Обычные ресурсы | ×2 | ×1 | ×2 |
| Древесина | ×2 | ×3 | ×6 |

Под древесиной здесь понимаются `Wood`, `FineWood`, `RoundLog`, `ElderBark`, `YggdrasilWood`, `Blackwood`: обычная, качественная, цельная древесина, древняя кора и последующие виды древесины. Если нужен итоговый ×6 только для обычного `Wood`, поменяй остальные пять записей на `1` во всех секциях конфига.

Настройка древесины уже записана в `Game/BepInEx/config/Gonfreecss.ResourceDropModifier.cfg`. Записи продублированы по биомам, потому что мод при загрузке мира сам определяет, к какой секции относится предмет. Для предмета используется одна секция; эти значения друг с другом не перемножаются. При первом запуске мод дополнит конфиг обнаруженными предметами со значением `1`.

Действуют штатные исключения Valheim для предметов, которым игра запрещает масштабирование добычи, и ограничения размера стопок. Содержимое существующих сундуков и инвентарей не умножается. При ресурсах мира ×1 древесина будет ×3; при ×2 — ×6; при ×3 — ×9. При неизменном модификаторе мира настройка удваивает прежний дополнительный множитель древесины. Для указанного в таблице результата нужен модификатор мира **×2**; его значение в существующем мире этим обновлением не меняется.

## Игра с друзьями и выделенный сервер

Установи одинаковую сборку всем игрокам на ПК. XPortal, Epic Loot и Adventure Backpacks требуют согласованных версий у участников и сервера. Лимит V+ оставлен 10, что достаточно для восьми человек. Для выделенного сервера используй его штатную установку BepInEx и серверные/общие плагины с конфигами. **PlantEasily устанавливается только на клиентов: автор прямо запрещает его установку на dedicated server.** Не копируй весь клиентский комплект на сервер без отбора; текущие установщики предназначены для клиентов, отдельного проверенного серверного пакета здесь пока нет. Обычному хосту через «Начать сервер» клиентский PlantEasily нужен. [Требования PlantEasily](https://thunderstore.io/c/valheim/p/Advize/PlantEasily/). Linux-клиент поддерживается отдельным скриптом. Xbox не запускает этот комплект клиентских DLL.

К существующей команде запуска выделенного сервера добавь:

```text
-modifier resources muchmore -modifier portals casual
```

`muchmore` соответствует ресурсам ×2; `casual` разрешает перенос металлов. Не меняй имя мира, пароль или остальные параметры сервера. Для обычного запуска через «Начать сервер» достаточно меню модификаторов мира.

## Первичная проверка в игре

1. В `BepInEx/LogOutput.log` проверь загрузку 16 плагинов: AutomaticFuel 1.5.1, Jotunn, AzuAutoStore, AzuCraftyBoxes, Quick Stack Store Sort Trash Restock 1.4.15, PlantEasily, XPortal, MushroomSync, ResourceDropModifier, ValheimPlus 0.10.2.0, Adventure Backpacks, Equipment and Quick Slots, PlantEverything, Epic Loot и двух детекторов общих библиотек. BepInEx — загрузчик. Для V+ особенно проверь ошибки Harmony/отсутствующих методов: версия игры новее заявленной автором.
2. На тестовом мире проверь посадку, создание предметов из сундука и меню назначения XPortal.
3. Положи образец ресурса в сундук и брось такой же предмет рядом: AzuAutoStore по умолчанию требует уже имеющийся предмет и проверяет окружение периодически, поэтому перенос не обязательно мгновенный. Клавиша K складывает подходящие предметы из инвентаря, не открывая сундук; `.` меняет масштаб миникарты.
4. Возьми руду и пройди через обычный деревянный портал. Если игра запрещает проход, проверь настройку Portals у мира/сервера.
5. Проверь добычу дерева и камня. При сравнении учитывай случайное исходное количество: сравнение двух разных деревьев само по себе не измеряет множитель точно.
6. Выполни сетевые проверки хранения, смерти/возврата вещей и перезапуска из [аудита](COMPATIBILITY.md). До этого не считать сборку проверенной для общего прохождения. Сохранения вне каталога игры нужно резервировать отдельно.

## Git и воспроизводимость

Репозиторий: [jullicdev-cyber/valheim-mod-pack](https://github.com/jullicdev-cyber/valheim-mod-pack). Первая версия без V+ отмечена тегом `v1.0.0`, версия с V+ — `v1.1.0`. В Git входят готовые файлы `Game`, исходные конфиги `config`, документация, скрипты сборки, версии пакетов и контрольные суммы. Кэш загрузок и ZIP в `dist` не отслеживаются.

Проверка готовой сборки из PowerShell, открытого в этой папке:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Verify.ps1
```

Повторная сборка в новую папку `dist/rebuild-ДАТА-ВРЕМЯ`:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Build.ps1
```

Скрипт использует закреплённые версии и сверяет SHA-256 перед распаковкой. Если архива нет в локальном кэше, требуется интернет. Самостоятельно обновления не скачиваются поверх закреплённых версий. Для проверки пересобранной папки передай её путь в `Verify.ps1 -PackDirectory`.

Для следующей версии измени исходный конфиг в `config`, пересобери пакет, обнови копию в `Game`, инвентарь `files.sha256.json` и описание изменений. Затем сделай новый коммит и тег. Не выполняй проверку эталонных хешей против уже запускавшейся игры: BepInEx добавляет и изменяет конфиги и журналы.
