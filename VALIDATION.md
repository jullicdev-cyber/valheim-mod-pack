# Проверка версии 1.0.0

Дата: 2026-09-25.

- Версия установленной игры по существующему журналу: Valheim 1.0.16.
- Скачаны 8 архивов с Thunderstore и Hexium; версии сверены с манифестами внутри архивов.
- Закреплены SHA-256 всех скачанных архивов в `mods.lock.json`.
- Проверены объявленные зависимости и минимальные версии: все присутствуют.
- Готовый комплект: 51 файл, включая 7 DLL плагинов и загрузчик BepInEx.
- Проверены SHA-256 всех 51 файлов по `files.sha256.json`.
- Повторная сборка выполнена через Windows PowerShell; все 51 файлов совпали с эталоном по SHA-256.
- Конфиг древесины составлен по исходному коду ResourceDropModifier 0.1.0: секции биомов, ключи prefab, дробный множитель `1.5`, синхронизация `LockConfiguration = true`.

Проверки выше подтверждают комплектность и воспроизводимость файлов. Игра с этим комплектом не запускалась; загрузка мира, взаимодействие модов и фактическая добыча не проверены в игре. Настройки мира ×2 и Portals Casual пользователь применяет отдельно по README. Изменений установленной игры или сохранений не выполнялось.
