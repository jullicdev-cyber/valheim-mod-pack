# Проверка сборки

## Версия 1.1.0

- ValheimPlus Grantapher: стабильный релиз GitHub 0.10.2.0 совпадает с пакетом Thunderstore 10.2.0; архив закреплён по SHA-256.
- Все 82 ключа нового конфига проверены по исходному коду тега 0.10.2.0, без использования устаревшей схемы.
- В метаданных DLL AzuAutoStore/AzuCraftyBoxes нет объявления BepInIncompatibility с ValheimPlus. Это не доказывает отсутствие всех конфликтов патчей.
- Состав: 9 пакетов, 53 файла; проверены объявленные зависимости и хеши. Множители V+ отключены, дополнительный множитель древесины по-прежнему 1.5 поверх штатных ресурсов ×2.
- Повторная сборка 1.1.0 совпала по всем 53 хешам; шесть тестов установщиков повторно прошли с новым составом.
- Поддержка игры 1.0.16 автором V+ не заявлена: в документации релиза указаны 1.0.15 и BepInEx 5.4.2350. Ни запуск игры, ни игровая совместимость этой версии сборки не проверялись.

## Версия 1.0.0 (история)

Дата: 2026-09-25.

- Версия установленной игры по существующему журналу: Valheim 1.0.16.
- Скачаны 8 архивов с Thunderstore и Hexium; версии сверены с манифестами внутри архивов.
- Закреплены SHA-256 всех скачанных архивов в `mods.lock.json`.
- Проверены объявленные зависимости и минимальные версии: все присутствуют.
- Готовый комплект: 51 файл, включая 7 DLL плагинов и загрузчик BepInEx.
- Проверены SHA-256 всех 51 файлов по `files.sha256.json`.
- Повторная сборка выполнена через Windows PowerShell; все 51 файлов совпали с эталоном по SHA-256.
- Конфиг древесины составлен по исходному коду ResourceDropModifier 0.1.0: секции биомов, ключи prefab, дробный множитель `1.5`, синхронизация `LockConfiguration = true`.

Проверки выше подтверждают комплектность и воспроизводимость файлов. Игра с этим комплектом не запускалась; загрузка мира, взаимодействие модов и фактическая добыча не проверены в игре. Настройки мира ×2 и Portals Casual пользователь применяет отдельно по README. Изменений установленной игры или сохранений не выполнялось.

## Проверка установщиков

- Windows: установка и повторная установка в тестовую папку с пробелами в пути, сохранение старых модов, отказ для неверной папки.
- Windows: откат после ошибки замены заблокированного `winhttp.dll` — старый BepInEx восстановлен.
- Linux: Python-логика установки, повторной установки, резервных копий, неверного пути и отката при искусственном сбое проверена на тестовых папках в Windows.
- Bash-обёртка проверена командой `bash -n` через Git Bash. Полноценная проверка на Linux и запуск игры не выполнялись: Linux/WSL-среда недоступна.
- Тесты запускаются командой `python scripts/test_installers.py`; временные папки оставляются для осмотра результатов.
- Проверено включение посторонних файлов и исполняемых файлов игры в полный бэкап, исключение прошлых бэкапов и остановка без замены модов при сбое резервного копирования.
